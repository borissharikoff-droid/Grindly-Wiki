    Perk IP Values

    Each perk adds to an item's total Item Power:

    PerkIP Formula
    atk_boostvalue × 30
    hp_boostvalue × 2
    hp_regen_boostvalue × 25
    def_boostvalue × 20
    streak_shield80 (flat)

    XP Formula

    Each skill has 99 levels. XP required for level L:

    xpForLevel(L) = floor(pow(L/99, 2.2) * 3,600,000)

    Max XP (level 99) = 3,600,000. See Skills → XP Formula for full table.
