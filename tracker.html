    Activity Tracker

    Grindly uses a background PowerShell process to detect what app you're working in and convert that time into skill XP. Windows-only. No keylogger — only app names are recorded.

    ~1.5sUpdate interval
    13Skills tracked
    Win32API based

    ⚙️ How It Works

    When you start a grind session, Grindly spawns a PowerShell subprocess that polls Windows APIs every ~1.5 seconds to detect the active foreground window.

    Active Window Detection

    Uses GetForegroundWindow (Win32) to identify the currently focused app. Reads the process name and window title.

    Keystroke Activity

    Uses GetAsyncKeyState to count keystrokes in the active window. Used to distinguish active work from passively watching a video.

    Idle Detection

    Uses GetLastInputInfo to measure time since the last user input. If idle too long, the session pauses automatically.

    Local Storage Only

    All activity data is stored locally in %APPDATA%/Grindly/grindly.sqlite. Only aggregated XP totals are synced to the cloud.

    📡 Data Format

    The PowerShell subprocess outputs a single line every ~1.5 seconds in this format:

    WIN:ProcessName|WindowTitle|KeystrokeCount|IdleMs

    Example: WIN:code.exe|App.tsx — Grindly|42|800
    The Electron main process parses this and maps the process name to a skill category. Only the category is stored — the full window title is used for display only and is not synced.

    💤 Idle Detection

    AFK Pause

    If no keyboard or mouse input is detected for a configurable idle threshold, the session automatically pauses and displays an AFK indicator. Time spent idle does not earn XP. Resuming activity restarts XP tracking immediately.

    The No AFK Run daily quest requires you to complete a session without triggering AFK pause — a reward for focused, uninterrupted work.

    🎯 App → Skill Mapping

    Each app is matched to a category based on the process name. The category then maps to a skill that earns XP.

    Warrior, Farmer, Crafter, Chef

    These four skills are earned through in-game actions, not tracked app time. Warrior XP comes from arena kills. Farmer XP from harvesting. Crafter XP from crafting. Chef XP from cooking. No desktop app is needed for these.

    🔒 Privacy

    What is recorded

    Process name (e.g. code.exe), activity category, and time durations. Window titles are used locally for display only.

    What is NOT recorded

    Screen content, file names, keystrokes content, clipboard, or any personal data. Keystroke count (not content) is used only for idle detection.

    What is synced

    Only cumulative XP per skill is synced to the cloud. Raw activity logs stay on your machine in the local SQLite database.

    Windows only

    The tracker uses Windows-specific Win32 APIs. macOS/Linux are not supported. The app will launch on other OSes but the tracker won't produce XP.
